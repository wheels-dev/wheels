## Signature

`renderNotFound()` — returns `void`

**Available in:** `controller`
**Category:** Rendering Functions

## Description

Renders a 404 Not Found response from a controller action: sets the 404 status, shows the
developer-facing error in development (when <code>showErrorInformation</code> is on) and the
<code>onmissingtemplate.cfm</code> page in production. This is the public entry point that scaffolds
and app controllers call so they do not depend on the internal <code>$throwErrorOrShow404Page</code>,
which stays in place for apps generated by 4.1.2. Defined as a controller mixin (not a
<code>wheels.Global</code> helper) so it is scoped to controllers and not mixed onto models.



## Parameters

<div class="wd-params-table">

| Name | Type | Required | Default | Description |
| ---- | ---- | -------- | ------- | ----------- |
| `message` | `string` | no | `Not Found` | The developer-facing message shown in development. |
| `type` | `string` | no | `Wheels.RecordNotFound` | The error type thrown in development. Defaults to `Wheels.RecordNotFound`. |
| `extendedInfo` | `string` | no | — | Optional extra developer detail shown in development. |
