Prune dangling images labelled with the service on every host.

## Synopsis

```txt title="
wheels deploy prune images [--destination=<name>] [--dry-run]
```

## Flags

| Flag | Description |
|------|-------------|
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print the commands without executing. |

## Behavior

Per host, emits `docker image prune -f --filter label=service=<service>`. Without `-a`, `docker image prune` removes only dangling (untagged) images, and only those carrying a `service=<service>` label. The `Dockerfile` that `wheels deploy init` generates sets no such label and the build adds none, so on a default setup this removes nothing; tagged images of old versions stay on the host.

## Example

```bash title="illustrative"
wheels deploy prune images
```
