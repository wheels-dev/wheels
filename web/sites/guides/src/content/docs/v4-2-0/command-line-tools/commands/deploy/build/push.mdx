Build the image locally and push it to the configured registry. Runs on the control machine; no SSH, no remote hosts.

## Synopsis

```txt title="
wheels deploy build push [--version=<v>] [--destination=<name>] [--dry-run]
```

## Flags

| Flag | Description |
|------|-------------|
| `--version=<v>` | Tag for the pushed image. Defaults to git short sha. |
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print the `docker buildx build --push` command without executing. |

## Behavior

Emits one command: `docker buildx build --push --tag <image>:<version> --file <dockerfile> <context>`, using `builder.dockerfile` (default `Dockerfile`) and `builder.context` (default `.`). The image is prefixed with `registry.server` unless the server is `docker.io`.

`builder.arch`, `builder.args` and `builder.remote` are not applied: the command has no `--platform`, `--build-arg` or `--builder` option, so it always builds on the control machine with the current default buildx builder.

## Example

```bash title="example"
wheels deploy build push
```
