Create a `docker buildx` builder on the control machine. One-time setup for multi-arch builds and remote builds.

## Synopsis

```txt title="
wheels deploy build create [--destination=<name>] [--dry-run]
```

## Flags

| Flag | Description |
|------|-------------|
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print the commands without executing. |

## When to run

Only when you want a named `kamal-<service>` buildx builder on the control machine, for example to select it yourself with `docker buildx use kamal-<service>`. `build push` and `wheels deploy` do not need it.

## Behavior

Emits `docker buildx create --name kamal-<service> --driver=docker-container` on the control machine. The builder is not selected with `--use`, and `build push` / `wheels deploy` do not pass `--builder`, so they build with your current default builder.

## Example

```bash title="Example"
wheels deploy build create
```
