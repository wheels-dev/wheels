App container lifecycle. Every verb targets containers labelled with the current service, optionally filtered by `--role`.

## Verbs

| Verb | Purpose |
|------|---------|
| [`boot`](/v4-2-0/command-line-tools/commands/deploy/app/boot/) | `docker run` new containers for the given version. |
| [`start`](/v4-2-0/command-line-tools/commands/deploy/app/start/) | `docker start` existing stopped containers. |
| [`stop`](/v4-2-0/command-line-tools/commands/deploy/app/stop/) | `docker stop` running containers. |
| [`details`](/v4-2-0/command-line-tools/commands/deploy/app/details/) | `docker inspect` for the given version's containers. |
| [`containers`](/v4-2-0/command-line-tools/commands/deploy/app/containers/) | `docker ps` filtered by service label. |
| [`images`](/v4-2-0/command-line-tools/commands/deploy/app/images/) | `docker images` for the app image. |
| [`logs`](/v4-2-0/command-line-tools/commands/deploy/app/logs/) | `docker logs` across every host. |
| [`live`](/v4-2-0/command-line-tools/commands/deploy/app/live/) | Clear the maintenance marker file. |
| [`maintenance`](/v4-2-0/command-line-tools/commands/deploy/app/maintenance/) | Write the maintenance marker file. |
| [`remove`](/v4-2-0/command-line-tools/commands/deploy/app/remove/) | Stop + remove containers for the given version. |

## Common flags

| Flag | Description |
|------|-------------|
| `--release=<v>` | Required for boot/start/stop/remove. Optional for details. Ignored by containers/images/logs/live/maintenance. |
| `--role=<name>` | Limit to one role. Default: all roles. A name that `deploy.yml` doesn't define stops the command with an error that lists the roles it does define. |
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print commands without executing. |

<Aside type="note" title="--release and --version">
`--release=<v>` is the documented form; the space form `--release <v>` works too. `--version=<v>` is accepted as an alias and reaches deploy dispatch on the current CLI runtime ([#2674](https://github.com/wheels-dev/wheels/issues/2674), closed). Purely numeric values such as `--release=1` work ([#3111](https://github.com/wheels-dev/wheels/issues/3111), closed).
</Aside>
