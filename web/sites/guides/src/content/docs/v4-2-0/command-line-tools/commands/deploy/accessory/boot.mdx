`docker run` the named accessory container on its pinned host(s).

## Synopsis

```sh title="synopsis"
wheels deploy accessory boot <name|all> [--destination=<name>] [--dry-run]
```

## Flags

| Flag | Description |
|------|-------------|
| `<name>` | **Required positional.** Accessory name, or `all` to fan out. |
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print commands without executing. |

## Behavior

For each targeted accessory, emits `docker run` with the image, `port`, `volumes`/`directories`, `env` and `cmd` declared in `deploy.yml`, on the `kamal` network. Container named `<service>-<accessory>`. A `files:` key is accepted without a warning, but nothing is uploaded.

## Example

```bash title="example"
wheels deploy accessory boot db
wheels deploy accessory boot all
```
