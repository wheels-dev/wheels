Build the app image locally and tag it with `:dirty`. No registry push; intended for local smoke testing.

## Synopsis

```txt title="
wheels deploy build dev [--destination=<name>] [--dry-run]
```

## Flags

| Flag | Description |
|------|-------------|
| `--destination=<name>` | Overlay destination config. |
| `--dry-run` | Print the `docker build` command without executing. |

## Behavior

Emits `docker buildx build --load --tag <image>:dirty --file <dockerfile> <context>` on the control machine, using the same `builder.context` and `builder.dockerfile` as a regular push. No push. The tag is always `dirty`. Useful when you want to verify the image builds before running `wheels deploy build push`.

## Example

```bash title="illustrative"
wheels deploy build dev
docker run --rm -it <image>:dirty   # spot-check locally
```
