- On Oracle 23ai and later, `t.boolean()` / `addColumn(columnType="boolean")` now create a native `BOOLEAN` column instead of a numeric column, and the model maps a `BOOLEAN` column to `cf_sql_bit`. A numeric column reached the model as a number, so automatic validation rejected `true` ("is not a number"). Oracle releases before 23ai get `NUMBER(1)` (#4097). Existing numeric boolean columns are unchanged: Oracle cannot change the datatype of a non-empty column, so convert one by adding a `BOOLEAN` column, copying the values and dropping the old column. A `BOOLEAN` value reads back as `1` / `0` on Lucee and Adobe CF and as `true` / `false` on BoxLang (#3897)
