- `wheels deploy` now mounts a top-level `volumes:` list on every app container (Kamal's format: `host:container` or `host:container:ro|rw`, a host path or a named volume), so a SQLite app can keep its database on the host across redeploys. Entries are validated, and accessory `volumes:` / `directories:` arguments are now quoted like the other docker arguments, so paths with spaces or special characters work (#4018)
