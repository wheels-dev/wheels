- `wheels packages` now checks a package's `wheelsVersion` range against the app's own `vendor/wheels` version, not the CLI's (falling back to the CLI version outside a project), and a dev CLI build (`0.0.0-dev`) treats every range as compatible, as documented. The manifest cache lives under the CLI home (so `LUCLI_HOME` isolates it), a registry other than the default gets its own `registries/<hash>/` cache, and `--offline` serves expired cached data or says plainly that nothing is cached yet (#3911)
