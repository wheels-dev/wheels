- Background jobs: `enqueue()`, `enqueueIn()` and `enqueueAt()` now persist the job class with the casing of the file on disk. On a case-insensitive filesystem (macOS, Windows, or a macOS checkout bind-mounted into Docker) a miscased `new app.jobs.sendwelcomeemailjob()` resolves, and Adobe CF reported its metadata name with the caller's casing, so the row named a class a case-sensitive Linux worker could not instantiate (`Wheels.JobClassNotFound`). The name is now canonicalized segment by segment against the directory listing before it is written (#3731)
