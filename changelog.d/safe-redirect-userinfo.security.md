- `redirectTo(url=...)`, `redirectTo(back=true)` and `startFormTag()`'s CSRF-token check no longer accept an absolute or protocol-relative URL that puts the current host in front of another one as userinfo. `$isSafeRedirectUrl()` took the host as everything before the first `:`, `/`, `?` or `#`, so it read `https://<your-host>:x@evil.com/` as same-host. Browsers read `<your-host>:x` as credentials and go to `evil.com`. That let an open redirect through with `allowExternalRedirects=false`, and made `startFormTag()` send the authenticity token to that host. The check now isolates the URL's authority (host and port) first and rejects any URL whose authority contains userinfo (`@`).
