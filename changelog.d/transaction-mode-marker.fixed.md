- An invalid `transaction` mode (e.g. a typo such as `save(transaction="commti")`) no longer leaves the connection marked as having an open transaction. The mode was rejected only after that marker was set, so if the app caught the error, every later save/update/delete on the same connection in that request silently ran with no transaction. `transaction="rollback"` then persisted its changes. The mode is now validated before any transaction state changes.
