- On Adobe ColdFusion with Oracle, reading a table's column metadata no longer leaves JDBC statements open. Every `cfdbinfo(type="columns")` call there retained about seven statements, with their row buffers, on the pooled connection for the connection's lifetime (enough to exhaust the heap of a long test run). `$dbinfo(type="columns")` now reads the same fields from the Oracle data dictionary (`ALL_TAB_COLUMNS` in the current schema, plus the primary-key constraint) with one ordinary query. A table the dictionary can't see in the current schema (reached through a synonym, or owned by another schema) still goes through `cfdbinfo`, as before. Other engines and databases are unchanged (#3732)
