- Test-runner URLs beyond `/wheels/core/tests` and `/wheels/app/tests` now bind the isolated test application too: the `testbox` and `tests_testbox` runner paths are matched (case-insensitively, anchored at the start of the path), so a run reached through a convention path such as `/wheels/testbox` no longer executes specs against the live application. On an app configured for isolation, a runner reached through a route that does not bind the isolated scope (a custom route) is now refused with a `409` naming the canonical runner path; apps without the isolation include keep their existing live-scope behaviour
