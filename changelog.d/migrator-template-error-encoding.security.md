- The migrator template-create endpoint no longer reflects an unknown template name into its HTML response. `createMigration` now allow-lists the requested template against the snippet files that actually exist (rejecting unknown names, embedded markup, and path-traversal attempts with a message that lists the valid templates instead of echoing the input), and the result is HTML-encoded at output. This closes a reflected-HTML/XSS path in the development-only migrator GUI.
