- The Wheels CLI's runtime is LuCLI 0.6.2.3. `wheels <command> --env=<name>` (and `--envfile`) now reach the command instead of being dropped; `wheels start --dry-run` no longer writes a default `lucee.json` and its preview shows `--name`; `wheels --timing cfml '…'` (a root option before a root subcommand) runs the subcommand; REPL history and `settings.json` stay inside the CLI's home instead of leaking into `~/.lucli`; `run <file>.cfm` no longer prints the built-in variables setup; hints name `wheels` rather than `lucli`. Over MCP, `generate type=app` is now refused as intended: LuCLI tells the Wheels module that a call came from an MCP tool (see #3980).
