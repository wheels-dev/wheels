- `enqueue()`, `enqueueIn()` and `enqueueAt()` accept `transactional=false`, and a job class can set `this.transactional = false`: the job is then written after the outermost Wheels-managed transaction ends, whether it commits or rolls back, so failure notices and audit records survive a rollback. With no transaction open it's written immediately; the default (`true`) is unchanged. A raw `transaction {}` block and a request that ends with `abort` aren't covered
