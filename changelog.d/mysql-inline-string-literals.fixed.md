- On MySQL and MariaDB, a string value that Wheels writes into the SQL text instead of binding it (every value with `parameterize=false`, and literals a `where` string leaves in place, such as function arguments) is now written as a hex literal when it contains a backslash, so it reads the same whatever the `sql_mode`; other values are unchanged. A backslash in those positions is now an ordinary character, as it already was in bound values: if you wrote `\\` there to mean one backslash, write `\`. `LIKE ... ESCAPE '\\'` and `ESCAPE '\'` both still mean a single backslash. The query-builder guide now lists which `where` values are bound.
