- `wheels map setup` writes a `.mcp.json` in the current project so AI assistants can query the app through the Wheels MCP server. It merges rather than overwrites — other servers you already list are preserved, and an existing `wheels` entry is corrected. Malformed JSON is left untouched and reported instead of replaced. (The command is `map`, not `mcp setup`: the runtime owns the `mcp` verb, so `wheels mcp setup` is resolved as a module lookup and never reaches the CLI)
