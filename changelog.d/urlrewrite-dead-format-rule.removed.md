- The "Convert dot to format parameter" rule is removed from the shipped `urlrewrite.xml` files (the app, the `wheels new` template and the examples). Its regex had doubled backslashes, so it never matched a normal URL; format suffixes such as `/posts.json` keep working, because the router reads them from the path. Existing apps can delete the rule from their own `public/urlrewrite.xml` (#4132)
