- `reload()` no longer truncates fractional values: it used to cast every numeric value that fit in 32 bits to an integer, so a decimal column holding `149.25` reloaded as `149` (and `-3.75` as `-3`). The object then saw the column as changed, and the next `save()` wrote the truncated value back to the database, even when only another field was edited. Only integer columns holding a whole number are normalized now.
