- Pagination helpers: `params` (string or struct) is no longer dropped when `pageNumberAsParam=false`. `nextPageLink()`, `previousPageLink()`, `firstPageLink()`, `lastPageLink()`, `pageNumberLinks()` and `paginationNav()` (including `viewStyle` presets) now keep the query string on route-segment page links, so `nextPageLink(route="postsPaged", pageNumberAsParam=false, params="sort=title")` on `posts/page/[page]` renders `/posts/page/3?sort=title` instead of `/posts/page/3`, matching legacy `paginationLinks()`.
