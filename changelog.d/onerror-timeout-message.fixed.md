- The `onError` fallback in the app's `public/Application.cfc` no longer reports "Wheels failed to initialize" for an error raised once the application is already running (for example a request timeout after startup); it renders and logs a running-app message instead. It also extends the request timeout (via `onErrorRequestTimeout`) before logging, so the `wheels.log` entry the minimal error page points at is written even after a request timeout. **Upgrade note:** existing apps should copy the updated `onError` / `$renderMinimalError` / `$logStartupFailure` block from the template's `public/Application.cfc`. ([#3965](https://github.com/wheels-dev/wheels/issues/3965))
