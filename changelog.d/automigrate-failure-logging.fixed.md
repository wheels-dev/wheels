- Migrator: a migration whose `up()` throws is no longer silent. `migrateTo()` folds the failure into the string it returns rather than throwing, so the application-start auto-migrate path (`autoMigrateDatabase`) discarded it entirely — one unrunnable migration stalled every migration queued behind it while the app booted healthy and nothing was logged. The migrator now records the failed step (direction, version, file, engine message and detail) to the `wheels` log at the point of failure, so every entry point sees it
