- A nested controller (`app/controllers/<package>/X.cfc`) that declares `extends="Controller"` now logs a hint to `wheels.log` to use `extends="app.controllers.Controller"` — a bare `extends` name resolves relative to the controller's own package, so the base controller cannot be found. The original component-not-found exception is preserved unchanged (its stack and cause are intact); the hint is added only to the log, which the error page already points to
