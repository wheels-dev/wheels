- `Job.processQueue()` processes jobs again on BoxLang with PostgreSQL and CockroachDB. Its candidate query passed the `maxrows` option, which BoxLang's PostgreSQL path rejects ("setLargeMaxRows is not yet implemented"), so every call returned an error and ran nothing. It now bounds the batch in the SQL itself, as `JobWorker` does. ([#4487](https://github.com/wheels-dev/wheels/pull/4487))
