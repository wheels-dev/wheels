- `migrate` and `create` MCP tool calls now honour every advertised parameter. Both rebuilt argv from named keys in struct order, so `{action: "info", "dry-run": false}` failed as `Unknown migration action: --no-dry-run`, `forget`/`pretend` lost their `version`, `diff` lost its `model`, and `{name, type}` reached `create` as `Unknown create type: --name=x`. A later MCP call no longer stays offline because an earlier one passed `offline`, and a bare `--name`-style flag no longer binds the literal `true` as a positional value (#2963)
