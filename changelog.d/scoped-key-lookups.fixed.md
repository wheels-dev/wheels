- `findByKey()`, `exists(key=...)`, `updateByKey()` and `deleteByKey()` now combine the key with an incoming scope chain, query builder or `where` argument (AND) instead of replacing it, so a key outside the scope or `where` returns `false` or matches nothing. Lookups with no `where` are unchanged. `exists()` no longer throws in development when it gets both `key` and `where`: it checks the key within the `where`, the same in every environment.
