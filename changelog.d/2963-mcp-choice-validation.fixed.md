- Fixed-choice CLI and MCP parameters now reject values outside their set instead of silently falling back: `routes` `format`, `seed` `mode` (an unknown mode used to generate rows), `test` `reporter`, `analyze` `target`, `destroy` `type` (which also exits non-zero now), the `db`/`packages`/`upgrade` verbs, `upgrade` `format`, `migrate` `action`, and the `generate`/`create` types. MCP tool schemas advertise the valid values as a JSON Schema `enum`, from the same `ArgSpec` declaration the parser enforces (#2963)
- `wheels migrate diff` on a missing model and a refused `wheels migrate rename-system-tables` now exit non-zero, and `wheels test` exits non-zero on any runner response without test counts (such as a missing-datasource error) (#2963)
