- Controllers include the application's global helper file (`app/views/helpers.cfm`) when each controller object is set up, and before `config()` runs, instead of in `wheels.Controller`'s pseudo-constructor. Every controller now gets the global helpers on engines that reuse a class's pseudo-constructor include across instances (RustCFML v0.721.0 and later), including a controller first created during application start-up. Global helpers still come before a controller's own helpers, so a controller helper can override one. A missing global helper file is skipped, and whether it exists is cached like the controller helper files when `cacheFileChecking` is on.
