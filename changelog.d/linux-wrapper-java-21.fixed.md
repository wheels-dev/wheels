- The `wheels` command from the Linux `.deb` and `.rpm` packages no longer fails with `UnsupportedClassVersionError` when `JAVA_HOME` points at a JDK older than 21, for example on GitHub's Ubuntu runners, where `JAVA_HOME` is Java 17. The launcher now uses `JAVA_HOME` only when it is Java 21 or newer. Otherwise it prints a one-line notice and uses an installed Java 21, and it skips an older `default-java` or `java` on the `PATH` too. With no Java 21 available, it exits with a message naming the Java 21 package to install. Homebrew and Scoop were not affected: their launchers always use the bundled or dependency Java 21
