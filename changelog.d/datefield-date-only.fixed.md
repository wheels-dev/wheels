- `dateField()` now emits a bare `yyyy-mm-dd` value for its `<input type="date">`. Bound to a `date`/`datetime` property that carries a time component (for example a `datetime` column), it previously rendered the full value (e.g. `2026-10-01 00:00:00`), which browsers cannot display in a date control, so the field showed blank. An already-bare date, an explicit non-date value, and an empty value are left unchanged.
