- Over MCP, `generate` with `type=app` (or its alias `a`) is now refused with `Wheels.InvalidArguments` instead of scaffolding an application into the MCP server's working directory, even for a client that skips the advertised input schema; `wheels generate app <name>` and `wheels generate --type=app <name>` in a terminal keep working. This uses the runtime-owned `__lucliMcpCall` marker a LuCLI build with wheels-dev/LuCLI#17 adds to every MCP `tools/call`; Wheels drops that marker before any command parses its arguments, so it is safe with today's LuCLI too (#3980)
