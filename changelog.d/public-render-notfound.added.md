- `renderNotFound(message, type, extendedInfo)` — a public controller helper for producing a 404 from app code: it sets the 404 status, shows the typed error in development (when `showErrorInformation` is on) and the `onmissingtemplate.cfm` page in production. Generated scaffolds now call it instead of the internal `$throwErrorOrShow404Page`, whose signature was never a public contract (that internal still works for apps generated by 4.1.2). It is a controller mixin (not a `wheels.Global` helper), so it is scoped to controllers and not added to models. Because it is a public controller helper it is now a reserved action name — an existing app with an action literally named `renderNotFound` would get `Wheels.ActionNotAllowed` instead of dispatching (no such action exists in the shipped examples or guides). An app that already defines its own `renderNotFound` controller helper transparently overrides this one, and generated scaffolds then call that helper with `message=`. ([#3900](https://github.com/wheels-dev/wheels/issues/3900))
