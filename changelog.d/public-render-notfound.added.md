- `renderNotFound(message, type, extendedInfo)` — a public controller helper for producing a 404 from app code: it sets the 404 status, shows the typed error in development (when `showErrorInformation` is on) and the `onmissingtemplate.cfm` page in production. Generated scaffolds now call it instead of the internal `$throwErrorOrShow404Page`, whose signature was never a public contract (that internal still works for apps generated by 4.1.2). Because it is a public helper mixed onto every controller, `renderNotFound` is now a reserved action name — an existing app with an action literally named `renderNotFound` would get `Wheels.ActionNotAllowed` instead of dispatching (no such action exists in the shipped examples or guides). ([#3900](https://github.com/wheels-dev/wheels/issues/3900))
