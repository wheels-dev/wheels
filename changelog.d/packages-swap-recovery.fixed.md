- A `wheels packages update` / `add --force` killed mid-swap no longer leaves the package only as a hidden `vendor/.wheels-pkg-previous-*` backup: the next `wheels packages` command restores it when `vendor/<name>/` is missing or incomplete, drops it when the new copy is in place, and says how to restore one it cannot attribute. A cross-volume install now copies into a hidden sibling and renames it in, so `vendor/<name>/` is never half-written (#3902)
