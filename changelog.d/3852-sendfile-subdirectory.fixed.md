- `sendFile(file="reports/2026/q1.zip")` finds the file under the `filePath` folder on disk (`public/files`) again when the app runs in a subdirectory whose URL rewrites fold `/public/` out of the URL, or that sets `set(subpath=...)`. The folder was built from `rootPath`, the app's URL path, so in those layouts it pointed one level above `public/` and `sendFile()` threw `Wheels.FileNotFound`. It is now built from the web root's folder on disk. Root-anchored and mapping paths, full disk paths and an absolute `directory` behave as before ([#3852](https://github.com/wheels-dev/wheels/issues/3852))
