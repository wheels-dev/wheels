- A failed `verifies()` that declares no `handler` and no redirect now ends the request with **HTTP 400** instead of a silent `200` with an empty `text/html` body — the declared precondition was not met. A JSON-format request receives a `{"error":"Verification failed"}` body; any other format receives an empty body (like a bare status). Verifications that declare a `handler` or redirect arguments are unchanged.
