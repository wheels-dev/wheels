- `set(baseUrl=...)` is now parsed once when the application starts, so a malformed value stops the application from starting with `Wheels.IncorrectConfiguration` instead of failing the first absolute URL a request builds. The parser also rejects a query (`?`), fragment (`#`), user info (`@`), a backslash, an unbracketed IPv6 host, an invalid host character and a port outside 1-65535, and accepts a bracketed IPv6 host (`https://[::1]:8443`). New apps from `wheels new` get a commented `set(baseUrl=...)` line in `config/settings.cfm` ([#3842](https://github.com/wheels-dev/wheels/issues/3842))
