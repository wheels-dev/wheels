- On SQLite, `updateAll()` now stores a date as ISO-8601 text, as `save()` does, instead of CFML's `{ts '...'}` string, which a `DATETIME` column then failed to read ("Error parsing time stamp"). `changeColumn()` to a date type converts such values left by earlier versions (`{ts}`, `{d}`, `{t}` literals and bare date-only or time-only text) to the form `save()` writes; the 4.1 to 4.2 upgrade guide has a query to find and repair them by hand (#4147)
