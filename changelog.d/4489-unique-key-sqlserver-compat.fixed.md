- When the `wheels_jobs.uniqueKey` upgrade can't finish, the warning and the `Wheels.Job.UniqueKeyUnavailable` error now say which step failed (adding the column, the backfill, or building the unique index) and give the manual fix for the database in use. On SQL Server below compatibility level 100, where the filtered unique index can't be built, they name the level and the real options: raise it, or create a plain unique index once every server runs 4.2 or later. Previously both messages advised the filtered index, which fails the same way. ([#4489](https://github.com/wheels-dev/wheels/issues/4489))
