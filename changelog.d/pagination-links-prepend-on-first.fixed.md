- View helpers: `paginationLinks(prependOnFirst=false)` no longer emits a mangled first item (e.g. a stray `-item">1</li>`) when the first page's `prependToPage` markup differs in length from the raw argument — the current page with `addActiveClassToPrependedParent=true` (which injects `active `), markup whose attributes are stripped by sanitization, or `encode=true` markup whose numeric entities are decoded. The helper now strips exactly the prefix it emitted for the first page, mirroring how `appendOnLast=false` already uses the sanitized suffix.
