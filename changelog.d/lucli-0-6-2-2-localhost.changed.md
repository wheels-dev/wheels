- The Wheels CLI's runtime is LuCLI 0.6.2.2. `wheels start` and `wheels server run` now listen on `127.0.0.1`, so a dev server is reachable only from your own machine. To reach it from a phone, a VM or another computer, start it with `--host 0.0.0.0`, or set `"bindAddress": "0.0.0.0"` in `lucee.json`; the startup output then warns that the server is reachable from your network. JMX monitoring (`monitoring.enabled`) listens on the same address, and LuCLI refuses to start unauthenticated JMX on a non-loopback address. Clients that resolve `localhost` only to `::1` need `http://127.0.0.1:<port>/`
