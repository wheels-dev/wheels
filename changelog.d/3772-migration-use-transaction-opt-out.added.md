- Migrations can opt out of the per-step transaction with `this.useTransaction = false`. The migrator then runs `up()`/`down()` without a transaction and records or removes the version only after the step succeeds, so a migration that touches a second datasource runs on Adobe ColdFusion, which rejects mixed datasources inside a transaction. When Adobe raises that error, the migrator's report now names the opt-out. The default per-step transaction is unchanged (#3772)
