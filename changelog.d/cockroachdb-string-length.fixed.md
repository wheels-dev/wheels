- On CockroachDB, `t.string()` now creates a `VARCHAR(n)` column instead of `STRING(n)`. The two are the same type in CockroachDB, but a `STRING(n)` column reports no length over JDBC, so automatic validations never enforced its limit; `VARCHAR(n)` reports it. Columns created by earlier versions keep the old behaviour until they are re-declared, for example `changeColumn(table = "users", columnName = "name", columnType = "string", limit = 100)` with the column's existing limit (#4101)
