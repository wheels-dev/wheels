- What middleware attaches to the request now reaches the controller. The `AuthMiddleware` result is available as `request.auth`, as documented, including the failed result under `allowAnonymous=true`, and the whole middleware context as `request.wheels.middlewareContext`. Before, the controller was built from the request params alone, so a controller behind `AuthMiddleware` could not tell who had authenticated.
- `AuthMiddleware` created without an `authenticator` now uses the one registered in the DI container (what `wheels generate auth` and `enableSession()` register), so the documented `new wheels.middleware.AuthMiddleware(strategies="...")` form no longer throws `Wheels.Auth.NoAuthenticator`.
- The default `AuthMiddleware` 401 body now has lowercase `error` and `status` keys; on Lucee they were serialized as `ERROR` and `STATUS`.
