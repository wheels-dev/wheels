- Wheels now initializes each `request.wheels` key when it is missing, even if `request.wheels` already exists. On Adobe CF 2025 the engine raises an error while loading the app's datasources during startup; the app's `onError` then created `request.wheels`, Wheels skipped initializing the request, and the first request after a restart failed with `Element WHEELS.HTTPREQUESTDATA.HEADERS is undefined in REQUEST`. What `onError` recorded is kept (#3726)
