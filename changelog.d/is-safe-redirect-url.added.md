- New controller helper `isSafeRedirectUrl(redirectUrl)` returns `true` when a URL stays on this site (a relative URL, or one on the current host), the same rule `redirectTo(url=…)` applies, so a return-to URL can be checked before it's stored or linked. Like every framework helper it can't be routed as an action: an app with a controller action named `isSafeRedirectUrl` must rename it.
