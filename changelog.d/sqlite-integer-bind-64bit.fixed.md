- On SQLite, `INTEGER` columns, including `INTEGER PRIMARY KEY` ids, are now bound as 64-bit integers, matching how SQLite stores them. A value or id above 2,147,483,647 used to fail on Adobe ColdFusion and was silently changed on Lucee (clamped to 2,147,483,647) and BoxLang (wrapped), so a find, update or delete by such an id could act on a different row. Existing `INTEGER` columns are protected without a migration (#4142)
