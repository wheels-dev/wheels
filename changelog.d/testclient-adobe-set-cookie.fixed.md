- `TestClient` keeps and returns cookies correctly on Adobe CF. Adobe hands repeated `Set-Cookie` headers over as a struct, and the client walked its keys instead of its values, so no cookie was kept and every request started a new session. And cookies went back through `cfhttpparam type="cookie"`, which URL-encodes again, so a value the server had already encoded (such as an encrypted token) arrived double-encoded. The client now reads every `Set-Cookie` shape and sends the jar back as one `Cookie` header, values exactly as the server set them; a value set with `withCookie()` is URL-encoded once.
