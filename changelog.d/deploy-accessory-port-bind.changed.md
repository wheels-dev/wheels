- **Breaking:** `wheels deploy` now requires an accessory `port:` to name a bind address, as Kamal does: `"<address>:<host port>:<container port>"` with an IPv4 or bracketed IPv6 address, optionally ending in `/tcp`, `/udp` or `/sctp` (e.g. `"10.0.0.20:5432:5432"` or `"127.0.0.1:5432:5432"`). A bare `port: 5432` or `"5432:5432"` now fails validation with a message naming the accessory; before, it went to `docker run --publish` as written and published on a random host port or on every interface. The published value is also quoted like the other docker arguments (#4067)
