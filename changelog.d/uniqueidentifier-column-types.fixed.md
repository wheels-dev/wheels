- `t.uniqueidentifier()` now creates a typed UUID column on every database: `UUID` on PostgreSQL, CockroachDB and H2, `CHAR(36)` on MySQL, SQLite and Oracle (SQL Server keeps `UNIQUEIDENTIFIER`). It previously emitted DDL with no type and SQL Server's `newid()` default, which failed everywhere else; `newid()` now becomes each database's own UUID generator. PostgreSQL `uuid` columns now bind as `cf_sql_other`, so finders on a `uuid` column, including ones created outside Wheels, work instead of failing with `operator does not exist: uuid = character varying`. Blank native UUID primary keys are now generated on PostgreSQL, CockroachDB and H2 too, and `generateUUID()` falls back to a formatted random version 4 UUID where Java isn't available (#4094)
