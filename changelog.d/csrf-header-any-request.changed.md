- From Wheels 4.2, CSRF protection accepts a valid `X-CSRF-Token` header on any non-GET request. Earlier versions also required `X-Requested-With: XMLHttpRequest`, which `fetch()` and Turbo don't send. When a request carries both a form field and a header, it passes if either holds a valid token (Rails' rule), so a form inside a cached fragment, whose hidden field holds another session's token, submits with the current token from the header. `startFormTag()` and `buttonTo()` gain `authenticityToken=false` to leave the hidden field out of cached markup; the caching guide shows how to supply the token at request time (#3959)
