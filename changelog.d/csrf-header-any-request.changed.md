- From Wheels 4.2, CSRF protection accepts a valid `X-CSRF-Token` header on any non-GET request. Earlier versions also required `X-Requested-With: XMLHttpRequest`, which Turbo and `fetch()` don't send. When a request carries both a form field and a header, it passes if either holds a valid token, as in Rails. `startFormTag()` and `buttonTo()` gain `authenticityToken=false` to leave the hidden field out. Use it for every form in cached markup that other visitors receive, and supply the token at request time from `csrfMetaTags()`; the caching guide shows how (#3959)
- Authenticity tokens are now compared exactly on every engine: the submitted value must be the whole session token (#3959)
