- `wheels test` can run a single spec file. `--filter` / `--directory` accept a spec file's dotted path (`tests.specs.models.UserSpec`) or its bare name (`UserSpec`), which is looked up anywhere under `tests/specs/`. A name that matches more than one file stops with the list of dotted paths instead of guessing. The app and core test runners run a `directory=` that names a spec file as that one bundle, where it used to discover 0 bundles, so the same works when calling the runner URL directly and with `bash tools/test-local.sh <area>/<Spec>`. A run that discovers no bundles no longer prints a green `0 passed` line above its failure (#3759)
