- `wheels console`: bare `exit` and `quit` now end the session like `/exit`. After a failed expression they exit non-zero (`Wheels.ConsoleFailed`), as end of input does, so a piped `bad expr; exit` is still reported as a failure. They used to be evaluated as CFML and fail with "variable [EXIT] doesn't exist", so a piped session that ended in `exit` exited 1 (#3892)
