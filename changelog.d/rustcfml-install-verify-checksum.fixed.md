- The CLI's RustCFML backend now verifies the engine binary against a pinned sha256 for its release asset before using it: a download that doesn't match is deleted and refused with `Wheels.RustCFML.ChecksumMismatch`, a cached binary is re-checked instead of trusted, and the binary is only renamed into place once verified. A failed download now reports `Wheels.RustCFML.InstallFailed` with its URL instead of a "Can't cast Complex Object Type Struct to String" error. The pins live in `tools/rustcfml/ENGINE_SHA256` (mirrored in `RustCFMLEngine.cfc`), and the daily engine auto-bump refreshes them from the release's published digests (#3824)
