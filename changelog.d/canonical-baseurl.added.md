- Added a `baseUrl` setting for a canonical host. `set(baseUrl="https://your-host")` in `config/settings.cfm` makes `urlFor()`, `linkTo()`, `redirectTo(onlyPath=false)`, and asset URLs build every absolute URL from that scheme/host/port instead of the incoming request — so emailed links and links generated in background jobs no longer depend on how the request arrived. Explicit `host`/`protocol`/`port` arguments still win, and leaving it unset keeps the historical request-derived behaviour. In `production` Wheels logs a one-time reminder when it is unset.
