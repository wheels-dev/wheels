- An association's `joinType` now accepts `left` and `left outer` as aliases of `outer` (all emit `LEFT OUTER JOIN`), and any other unknown value throws `Wheels.InvalidJoinType` when the association is registered. `joinType="left"` used to emit `LEFT JOIN`, which the nested-include grouping didn't recognise, so a nested include under it (`include="classifications(tag)"`) was silently dropped and the query failed with an unknown column. The grouping now throws instead of dropping a nested join it can't place (#3936)
