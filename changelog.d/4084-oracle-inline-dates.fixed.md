- On Oracle, comparing a date or timestamp column with a value written into the SQL text (`parameterize=false`), such as `where="createdAt > {ts '2000-01-01 00:00:00'}"` or `where="createdAt > '2000-01-01'"`, now returns the matching rows: an ISO value is written as an ANSI `TIMESTAMP '...'` / `DATE '...'` literal, which reads the same under any session date format, instead of a quoted string that fails with `ORA-01843` (#4084)
