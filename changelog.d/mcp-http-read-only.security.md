- The deprecated HTTP MCP endpoint (`/wheels/mcp`) is now read-only: only the read-only `analyze` tool can be listed or called there. Mutating and command-executing tools (`generate`, `migrate`, `test`, `validate`, `server`, `reload`, `develop`) are refused with a message pointing to the canonical stdio MCP server (`wheels mcp wheels`). This removes an unauthenticated file-write path that was reachable over the development-only HTTP surface (including via a GET whose query promoted it to a POST). The stdio MCP server keeps all tools.
