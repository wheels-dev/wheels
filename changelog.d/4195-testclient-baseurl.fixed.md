- Fixed `$testClient()` and `BrowserTest` base-URL auto-detection so a loopback test request reaches the running server when the host port is mapped to a different internal port (e.g. inside a container). When a mapping is detected the base URL now uses the server's local listener — its scheme and port, via the loopback address — and is byte-for-byte unchanged otherwise. Explicit `testClientBaseUrl` / `browserTestBaseUrl` overrides still take precedence. ([#4195](https://github.com/wheels-dev/wheels/issues/4195))
