- `wheels docs fetch` no longer deletes a `public/wheels-docs` folder the app keeps for itself, and editing the app's docs mirror no longer changes the shared docs cache under `~/.wheels/docs/<version>/`. The mirror is now a real copy instead of hardlinks, built beside the target and renamed into place. It is replaced only when it is a docs mirror (it holds the bundle's `manifest.json`) and only when missing or out of date. A `public/wheels-docs` without `manifest.json` is left alone with a message saying so. If the mirror can't be copied or swapped in, the command now exits non-zero instead of reporting success. This matches the Linux package wrapper (#3821) (#3848)
