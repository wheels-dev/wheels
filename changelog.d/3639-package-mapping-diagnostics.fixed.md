- `PackageLoader` now verifies that each package mapping alias it registers is actually resolvable by the engine (`ExpandPath()` probe) and reports the ones the engine ignored through `getUnresolvedMappings()`, plus one boot log line. Lucee ignores `application.mappings` written after application start, so a package referencing a sibling alias used to fail at first use with a bare "could not find component" while the loader reported the alias as registered (#3639)
