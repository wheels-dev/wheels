- `wheels upgrade check` without `--to=` now exits non-zero (`Wheels.UpgradeCheckFailed`) when the latest Wheels release can't be looked up, for example offline or when GitHub rate-limits the request. It used to print a warning and exit 0 without scanning anything, so a CI gate passed and `--strict` was bypassed. The message names the reason and suggests `--to=<version>`; `--format=json` prints a `{"success": false, "error": ...}` document before exiting non-zero
