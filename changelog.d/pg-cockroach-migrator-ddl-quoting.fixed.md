- The PostgreSQL and CockroachDB migrators now quote generated DDL identifiers lowercase, matching their model adapters, so migrations can create reserved-word tables and columns (e.g. `"order"` / `"group"`) and still alter, rename or drop existing unquoted schemas. `migratorObjectCase` only applies to adapters that do not quote DDL.
