- `wheels generate scaffold` with a `boolean` property, such as `published:boolean`, no longer generates specs that fail on SQLite with "Published is not a number". The generated test data used `true`; a migration's boolean column is `INTEGER` on SQLite, so the model's automatic numericality validation rejected it. The generated specs now use `1`, which that validation accepts and which `BIT`/`BOOLEAN` columns on the other databases store as true. In specs generated with an earlier version, change `"published": true` to `"published": 1` (#3868)
