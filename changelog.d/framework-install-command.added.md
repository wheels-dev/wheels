- `wheels framework install` installs the CLI's bundled framework into `vendor/wheels/` for an app that has none (for example one moving off CommandBox), creating `vendor/` if needed and pinning `box.json`'s `wheels-core` when present. It refuses when a framework is already installed (use `wheels upgrade apply` to replace one), and `--to=<version>` must match the bundled version (no downloads)
