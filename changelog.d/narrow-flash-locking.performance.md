- Flash locking is now scoped to where the data lives: session-stored flash takes a per-session lock instead of one application-wide lock, so users no longer queue behind each other on every request, and cookie-stored flash (request-local) is no longer locked at all. The end-of-request `$flashClear()` also skips its exclusive write when the session flash is already empty. Under a 128-user load test this lifted throughput 10–14%.
