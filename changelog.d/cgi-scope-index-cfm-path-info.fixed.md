- Routing: `$cgiScope()` now actually strips a leading `/index.cfm/` from `path_info`. The cleanup discarded the result of `Replace()`, so on servers that report the front controller in the path (e.g. IIS returning a blank `cgi.path_info`, where the fallback copies `request_uri` such as `/index.cfm/users/list`) the router received `index.cfm/users/list` and matched no route. The strip is anchored to the leading segment and case-insensitive, so a later segment like `/docs/myindex.cfm/x` is left untouched.
