- `wheels migrate unlock` reports who holds the migration lock: the host, owner id, how long it has held it and when its lease expires. While a live instance holds it, the command exits non-zero and names `wheels migrate unlock --force`, which removes the lock and prints what it removed (`--yes` works too). The `migrate` MCP tool has the same `unlock` action, and it only removes the lock when `force` is true. In the framework, `migrationLockStatus()` returns the same details and `releaseMigrationLock(force)` removes the lock: without `force`, only an expired lease. The `Wheels.MigrationLockTimeout` error now points at the command (#4209).
