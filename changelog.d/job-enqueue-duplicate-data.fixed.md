- `Job.enqueue()`, `enqueueIn()` and `enqueueAt()` no longer mutate the `data` struct the caller passes. The framework's internal keys (`$wheelsJobTimeout` and, when present, the tenant context) were added to the caller's struct because CFML passes structs by reference; the data is now duplicated before those keys are added. ([#3887](https://github.com/wheels-dev/wheels/issues/3887))
