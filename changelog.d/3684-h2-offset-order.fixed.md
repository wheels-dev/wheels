- On H2 (the 1.3.172 driver Lucee bundles), a query builder `offset()` without `limit()` returned rows in the wrong order. The builder asks for "no limit" as `LIMIT 2147483647`, and H2 1.3.172 mis-sorts once `LIMIT + OFFSET` passes the 32-bit maximum. The H2 adapter now clamps the limit so the sum stays at that maximum, which also covers an explicit huge `limit()` with an offset (#3684)
