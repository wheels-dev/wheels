- Path-containment guards that confine a resolved target to a root directory — database dump output, zip extraction, package manifest mappings, dev-UI asset and offline-docs serving, and image-tag source resolution — now compare canonical paths **exactly** (case-sensitively) with a separator-qualified boundary, through a shared `wheels.PathGuard` helper. Both the root and the candidate are canonicalised the same way, so a root configured in a different case than its on-disk spelling still resolves its own descendants. The always-on lexical checks and the existing authorization gates are unchanged.
