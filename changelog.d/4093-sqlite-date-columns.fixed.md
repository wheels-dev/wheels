- On SQLite, `t.date()`, `t.datetime()`, `t.time()` and `t.timestamp()` now declare `DATE` / `DATETIME` / `TIME` columns instead of `TEXT`, and the model validates columns with those declared types as dates. Automatic validations used to see a string and accept a value like `"not a date"`. Values are still stored as ISO-8601 text. A declared `DATE` or `TIME` column now binds as text too, instead of being stored by the driver as epoch milliseconds. Existing `TEXT` date columns are unchanged and keep the column-name check; convert one with `changeColumn(columnType="datetime")`. A column declared `DATE` or `TIME` outside the migrator may hold old epoch-millisecond values: convert them first, as the 4.1 to 4.2 upgrade guide shows (#4093)
