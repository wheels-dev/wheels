- `wheels test --filter=<SpecName>` no longer misnames a spec reached through a symlink into a sibling folder whose name starts with the spec root's (such as `tests/specsOld`): it used to produce a wrong dotted path like `tests.specs.ld.FooSpec` and run 0 bundles. A spec folder reachable twice through a symlink inside the spec root is also no longer reported as an ambiguous match with two identical paths (#3800)
