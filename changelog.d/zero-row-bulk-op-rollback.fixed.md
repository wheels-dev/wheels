- Fixed a data-loss bug where a `deleteAll` or `updateAll` matching zero rows, run inside a raw `transaction {}` block, silently rolled back the entire enclosing transaction on Lucee and Adobe. A zero-row bulk operation is now correctly treated as success rather than a failed operation. Wheels-managed transactions (`transaction()` / `invokeWithTransaction`) were never affected. ([#3944](https://github.com/wheels-dev/wheels/issues/3944))
