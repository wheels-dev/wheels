- On MariaDB 10.2.7 and later, column defaults are read correctly. MariaDB reports them as SQL expressions: a nullable column without a default as the text `NULL`, and a string default as a quoted literal (`'draft'`). Wheels took the text `NULL` as a real default, so `validatesPresenceOf` was skipped for an unset nullable column on create, and string defaults kept their quotes. The MySQL adapter now normalizes them on MariaDB; a literal string default `'NULL'` stays the text `NULL`, and MySQL is unchanged. (#3927)
