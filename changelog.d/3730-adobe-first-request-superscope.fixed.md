- The first request after a cold start no longer fails with HTTP 500 on Adobe ColdFusion 2023 and 2025. `onApplicationStart` failed with `java.util.EmptyStackException` at `NeoPageContext.popSuperScope` while creating the internal `wheels.Public` component. The cause is an Adobe engine bug, triggered the first time a Global mixin creates a Global subclass. Wheels now works around it with no application changes. Health checks and readiness retries usually hid it by absorbing that first request. ([#3730](https://github.com/wheels-dev/wheels/issues/3730))
