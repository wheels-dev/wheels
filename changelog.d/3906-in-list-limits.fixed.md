- An IN list longer than 1000 values (`whereIn()`, `whereNotIn()` or a hand-written `IN (...)`) now runs on Oracle 19c and earlier, which accept at most 1000 values per list (`ORA-01795`): Wheels splits it into parenthesised groups, OR-joined for `IN` and AND-joined for `NOT IN`, with every value still bound. On SQL Server, which binds at most 2100 parameters per statement, a query that would bind more now fails before it runs with `Wheels.TooManyParameters`, naming the limit and the count, instead of the driver's "too many parameters" error (#3906)
