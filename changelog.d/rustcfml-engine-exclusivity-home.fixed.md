- RustCFML engine: `wheels start --engine=rustcfml` (and `wheels engines rustcfml start`) now refuses with `Wheels.EngineConflict` while the project's Lucee server is running, and `wheels start` refuses while its RustCFML server is running. Both engines used to run at once on different ports, and the CLI's HTTP commands targeted whichever one port detection picked. `wheels stop` now stops both: it used to stop RustCFML and leave Lucee running. RustCFML state also honours `-Dlucli.home` ahead of `$LUCLI_HOME`, as the rest of the CLI does, so `wheels engines rustcfml status` no longer misses a running server under a launcher that passes the property (#3913)
