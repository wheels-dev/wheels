- `wheels upgrade apply` now updates a CommandBox app's `box.json` `wheels-core` version (an exact version or a `^`/`~` range, in `dependencies` and `devDependencies`) to the framework it installed, and prints the change. Before, the old pin stayed, and a later `box install` copied the old framework back over the new `vendor/wheels/`, leaving a mix of both versions. Other specs (`4.x`, a channel, a `forgebox:` spec) are left alone with the exact line to change. If `box.json` isn't valid JSON, `apply` refuses before changing anything.
