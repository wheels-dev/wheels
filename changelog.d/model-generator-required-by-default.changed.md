- `wheels generate model` / `scaffold` now treat columns as **required by default**: an unmarked `name:type` column is created `allowNull=false` and added to `validatesPresenceOf`, so the generated model and migration agree. Mark a column nullable with `name:type:optional` (excluded from `validatesPresenceOf`), or give it a default with `name:type=value` (also excluded — the default fills an absence); the two combine as `name:type=value:optional`. A `belongsTo` foreign-key column is required by default. Previously every column was added to `validatesPresenceOf` even though the migration made it nullable, so a freshly generated model rejected any row that left a blank column. `:optional` uses the word rather than `?` because zsh (the macOS default shell) treats a bare `?` as a glob.
