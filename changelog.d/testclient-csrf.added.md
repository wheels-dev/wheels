- `TestClient` (`$testClient()`) sends the session's authenticity token to forgery-protected actions the way a browser does. It picks up the token from a page it fetched (the `csrf-token` meta tag from `csrfMetaTags()`, or a form's `authenticityToken` field) and sends it on POST, PUT, PATCH and DELETE as the `X-CSRF-Token` header and, on a form body, the `authenticityToken` field. The token is dropped when the session cookie changes, as at login, and a token or field the test passes itself wins. New methods: `csrfToken()`, `fetchCsrfToken(path)`, `withCsrfToken(token)` and `withoutCsrfToken()`.
