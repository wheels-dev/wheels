- `PackageLoader` resolves a package's entry-point CFC deterministically instead of taking whichever `*.cfc` the directory listing returns first. A package with more than one root CFC now declares it with `"main": "Sentry"` in `package.json`, or is matched by the package name (`wheels-seo-suite` → `SeoSuite.cfc`); anything still ambiguous fails loudly and names the candidates instead of loading the wrong component (#3639)
