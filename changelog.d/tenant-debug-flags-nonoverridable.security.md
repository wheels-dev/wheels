- A per-tenant `config` override can no longer switch on `showDebugInformation` or `enablePublicComponent` for a tenant's requests. `$get()`'s tenant-override guard already excluded `showErrorInformation`, but not the other two debug flags it is grouped with everywhere else, so a per-tenant config could expose debug output or the public-component surface for that tenant. All three debug flags are now non-overridable per-tenant. ([#3880](https://github.com/wheels-dev/wheels/issues/3880))
