- `travelTo(moment, callback)` on `wheels.WheelsTest` freezes the framework clock for the callback, so time-dependent behaviour is testable deterministically without sleeping. Framework code reads the clock through a `$now()` / `$tick()` seam that returns the live clock in production (no behaviour change) and the frozen instant under `travelTo()`: cache expiry and culling, the `RateLimiter` rate-limit windows, and model `createdAt` / `updatedAt` timestamps honour it. The override is request-scoped and restored in a catch-free finally, so it never leaks into another spec
