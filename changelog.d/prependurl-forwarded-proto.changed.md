- `$prependUrl` (used by `urlFor(onlyPath=false)` and asset URLs) still derives an absolute URL's `http`/`https` scheme from the client-controlled `X-Forwarded-Proto` header as before, so an app behind a TLS-terminating proxy keeps its `https://` URLs. When the header is the only reason for `https://` and the app has not set `set(trustProxyHeaders=true)`, Wheels now logs a one-time warning to `wheels.log`. **Wheels 4.2 will require `trustProxyHeaders=true` to honour `X-Forwarded-Proto` for the scheme and otherwise ignore it** (matching `isSecure()`); apps behind a trusted reverse proxy should set `trustProxyHeaders=true` now. The real socket TLS state is unaffected
