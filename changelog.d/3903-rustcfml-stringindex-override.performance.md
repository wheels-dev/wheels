- The RustCFML engine adapter now pins `stringIndexIsLinear()` to false explicitly, so the WHERE-clause literal masker always takes the linear char-array path on RustCFML. Previously this relied on the Base adapter's `java.lang.String` capability probe failing there; because RustCFML already shims part of the `java.*` surface, a future build that shimmed `java.lang.String` would have flipped the probe and silently reverted RustCFML to the O(n²) index scan. The explicit override removes that risk (follow-up to #3903)
