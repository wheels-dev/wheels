- `wheels docs fetch` now mounts an already-installed docs bundle into the current app's `public/wheels-docs` (a second app no longer needs `--force`), unpacks the bundle with Java instead of a shell `unzip` (so a CLI home path with a space works, and Windows needs no `unzip`), refuses archive entries that point outside the docs directory, and honours `--offline` / `WHEELS_OFFLINE=1` by refusing the download while still mounting an installed bundle (#3894, #3899).
