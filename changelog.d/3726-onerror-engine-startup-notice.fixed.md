- On Adobe ColdFusion 2025 without the optional graphqlclient package, the first request after a start no longer fails with HTTP 500 because of the engine's pre-start "The graphqlclient package is not installed." notice. `onError()` recognizes that exact notice, logs it to `wheels.log`, and lets the request continue. A clean first request also needs the framework fix for #3730. Existing apps on Adobe 2025 that do not install graphqlclient must add the guard to their own `public/Application.cfc` by pasting the block at the top of `onError()` from the current template. Installing the package (`cfpm install graphqlclient`) is the alternative (#3726)
