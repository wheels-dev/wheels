- On Adobe ColdFusion, a model write (`create()`, `save()`, `update()`, `delete()`) inside a raw `transaction {}` block no longer fails with "Nested cftransaction tag should specify same isolation level as the parent". When Adobe rejects the default `read_committed` level of a nested model transaction, the write now joins the outer block at its isolation level. An `isolation` you pass yourself is never dropped: if it differs from the outer block's, the call throws `Wheels.TransactionIsolationMismatch` explaining the fix (#4045)
