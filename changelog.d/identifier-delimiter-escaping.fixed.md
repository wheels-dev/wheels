- Identifier quoting now doubles a closing delimiter that appears inside a table or column name (`"` becomes `""`, a backtick becomes two, `]` becomes `]]`), so such a name stays a single identifier. This applies to the SQLite, PostgreSQL, CockroachDB, Oracle, MySQL and SQL Server model adapters, and to the SQLite, MySQL and SQL Server migrators, where a dotted `schema.table` name is still quoted part by part. Names without those characters are quoted exactly as before.
