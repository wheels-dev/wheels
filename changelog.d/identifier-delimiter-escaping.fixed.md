- Identifier quoting now doubles a closing delimiter that appears inside a table or column name (`"` becomes `""`, a backtick becomes two, `]` becomes `]]`), so the generated SQL stays well-formed and such a name stays a single identifier. This applies to the SQLite, PostgreSQL, CockroachDB, Oracle, MySQL and SQL Server model adapters, and to the SQLite, MySQL and SQL Server migrators, where a dotted `schema.table` name is still quoted part by part. Oracle does not allow a double quote inside a quoted name at all, so there the escaping only keeps the SQL well-formed. Names without those characters are quoted exactly as before.
