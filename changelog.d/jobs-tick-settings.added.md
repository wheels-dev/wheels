- The jobs tick route (`/wheels/jobs/tick`) takes its batch from settings: `jobsRunnerTickMaxJobs` (most jobs per call, default `1`), `jobsRunnerTickTimeout` (seconds per job, default `300`) and `jobsRunnerTickQueues` (comma list, default every queue). The defaults keep today's behaviour of one job per call. They are settings rather than request parameters, so a caller holding the token can't widen the work one request does.
