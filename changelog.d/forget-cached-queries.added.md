- `forgetCachedQueries()`, a public helper to drop the per-request finder cache that `cacheQueriesDuringRequest` fills: `model("Post").forgetCachedQueries()` clears one model's slot (and returns the model for chaining), `forgetCachedQueries("Post")` clears it by name from anywhere, and `forgetCachedQueries(all = true)` clears every model's. A bare call outside a model throws rather than silently wiping everything. Replaces the old advice to delete the reserved `request.wheels["$queryCache"]` key directly (#4364)
