- Browser specs that do not run no longer count as passed. Without Playwright (or in CI without `WHEELS_BROWSER_CI_ENABLE`), each `browserDescribe()` spec is reported as skipped, with the reason. When Playwright is installed but the browser cannot start, each one is reported as an error with the launch message, unless `WHEELS_BROWSER_SKIP_LAUNCH_FAILURES=true` asks to skip them. `wheels test` now counts skipped specs (`3 passed, 1 skipped`, not green) and lists each skip reason.
