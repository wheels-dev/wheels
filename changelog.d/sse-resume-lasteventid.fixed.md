- SSE channel resume now honours the bundled `WheelsSSE` client's `lastEventId` url parameter, not just the `Last-Event-ID` header, so a reconnect replays the events it missed out of the box — you no longer have to forward `params.lastEventId` from the action (the header still wins when both are present). The channel `events` filter now trims whitespace, so `events="a, b"` matches `b` (#4375)
