- `$prependUrl` (used by `urlFor(onlyPath=false)` and asset URLs) now honours the `X-Forwarded-Proto` request header only when `set(trustProxyHeaders=true)` is enabled, matching `isSecure()`. The header is client-controlled, so an app that was not behind a trusted proxy could previously be induced to emit `https://` absolute URLs from a spoofed header. The real socket TLS state (`server_port_secure`) is still honoured unconditionally. An app behind a trusted reverse proxy that terminates TLS should set `trustProxyHeaders=true` so absolute URLs keep their `https://` scheme
