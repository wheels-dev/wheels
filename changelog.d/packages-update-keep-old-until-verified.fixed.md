- `wheels packages update <name>`, `wheels packages update --all` and `wheels packages add --force` no longer delete the installed package before the new version has been downloaded and verified. The old copy was removed first, so an offline machine, a GitHub error or a stale registry sha256 left the app without a package it depends on. The new version is now downloaded, checksummed and extracted into a staging directory under `vendor/` first, and only then swapped in; if anything fails before or during the swap, the installed copy stays as it was (#3826)
