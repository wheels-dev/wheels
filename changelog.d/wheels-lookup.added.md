- `wheels lookup <query>` looks up the Wheels API reference and the guides offline, and so does the new `lookup` MCP tool. A function name (`findAll`, `model.findAll`) prints its full entry: signature, parameters, example and link. A phrase (`nested resources`) lists the best-matching guide sections and functions, each with a link and an id that prints the whole entry. The CLI ships a docs index for its own framework version, built at release and snapshot time, so no network, server or project is needed.
