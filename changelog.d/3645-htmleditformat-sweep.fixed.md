- Adobe ColdFusion 2025 no longer breaks the framework's own debug surfaces: the debug bar's complexity panel, the development error page's code frame, the docs viewer's extended examples, and legacy RocketUnit failure messages all called `HtmlEditFormat()`, a BIF Adobe CF 2025 removed (`Variable HTMLEDITFORMAT is undefined`). Each call now goes through `$encodeForDisplayText()`, which keeps using the BIF where the engine provides it (it preserves `/`, so file paths stay readable) and falls back to an equivalent local escaper otherwise. On the compat matrix the complexity panel alone produced twelve `Variable HTMLEDITFORMAT is undefined` errors on every adobe2025 leg, and a new structural guard (`HtmlEditFormatGuardSpec`) fails the suite if a direct BIF call reappears anywhere under `vendor/wheels` (#3645)
