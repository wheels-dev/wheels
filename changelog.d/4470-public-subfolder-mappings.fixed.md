- A `.cfm` page in a subfolder of `public/` no longer fails with `can't find component [wheels.events.EventMethods]`. `public/Application.cfc` built its mappings, and `config/app.cfm` its SQLite and H2 paths, with `expandPath("../...")`, which resolves against the requested page's directory. The `wheels new` template now builds them from `this.wheels.projectRoot`, derived from `Application.cfc`'s own path. Existing apps make the same edit: see the 4.1 to 4.2 upgrade guide (#4470)
