- `sendEmail(file="reports/q3.txt")` attaches the file from the `filePath` folder on disk (`public/files`), as the argument docs say. Only a bare file name was resolved there; a relative path with a subfolder went to `cfmailparam` unchanged, which looked for it next to the framework's own templates and failed with "the file doesn't exist". Relative attachments now resolve the same way as `sendFile()`'s files; absolute paths and URLs are passed through as before ([#3852](https://github.com/wheels-dev/wheels/issues/3852)) (#3857)
