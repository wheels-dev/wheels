- The local docs mirror that `wheels docs fetch` puts in `public/wheels-docs/` (about 300 MB) is no longer committed or shipped by accident. New apps list it in `.gitignore`, `wheels deploy init` lists it in `.dockerignore`, and the mirror now carries its own `.gitignore` so existing apps keep it out of git too. In an existing app's `.dockerignore`, add `public/wheels-docs` yourself.
