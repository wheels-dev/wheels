- `wheels upgrade apply` names old framework backups still inside `vendor/` (`vendor/wheels.bak-*` left by earlier versions), which make the framework log an error on every start, and says to move or delete them. When the backup can't be made (a separately mounted `vendor/`, for example), it says nothing was changed and gives the workaround: copy `vendor/wheels/` yourself, then use `--nobackup`.
