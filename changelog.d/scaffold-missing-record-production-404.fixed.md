- `wheels generate scaffold`: a request for a record that doesn't exist (`GET /posts/999999`) now returns 404 in production too. The generated `requireRecord()` filter threw `Wheels.RecordNotFound`, which only the development error page turns into a 404, so production served its generic 500 page. The filter now calls `$throwErrorOrShow404Page()`, which sets 404 and shows the error in development or `app/events/onmissingtemplate.cfm` in production. **Controllers generated with an earlier version** should replace the `Throw(` call in their `requireRecord()` with `$throwErrorOrShow404Page(` (same arguments), and apps that keep `app/snippets/CRUDContent.txt` should make the same change there so later scaffolds pick it up (#3868)
