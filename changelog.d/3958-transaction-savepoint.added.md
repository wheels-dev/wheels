- `transaction="savepoint"` runs `invokeWithTransaction()` or any persistence method as a nested unit: inside an open transaction it rolls back only its own writes when the method returns `false` or throws, and the outer transaction carries on. With no transaction open it behaves like `commit`. Records in a rolled-back unit get `afterRollback` right away and never `afterCommit`. Each unit runs a primary-key read before setting its savepoint, because Lucee drops a savepoint set before a transaction's first query (#3958)
