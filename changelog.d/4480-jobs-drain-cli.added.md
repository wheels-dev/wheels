- `wheels jobs drain` stops the running server from starting new background jobs while the jobs it is already running finish, and `wheels jobs resume` lifts it. For deploys, `wheels jobs drain --wait` blocks until the server has no running jobs (up to 600 seconds, or `--wait=<seconds>`) and exits with an error if jobs are still running, so the server can be stopped safely. `--expires=<seconds>` sets when the drain lifts itself (default 3600; 0 = until resumed). `wheels jobs status` now also shows this server's running jobs, cap and drain. ([#4480](https://github.com/wheels-dev/wheels/issues/4480))
