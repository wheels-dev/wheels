- The Linux `.deb`/`.rpm` `wheels` command no longer deletes and re-copies `public/wheels-docs` on every run from an app root, which wiped anything you had put there, briefly removed the docs assets from a running dev server, and hardlinked the copy so editing it changed the shared `~/.wheels/docs` cache. It now copies the offline docs only when the mirror is missing or from another version, leaves a `public/wheels-docs` it did not create alone, and warns instead of aborting your command if the copy fails
