- The Linux `.deb`/`.rpm` `wheels` command no longer deletes and re-copies `public/wheels-docs` on every run from an app root, which wiped anything you had put there, briefly removed the docs assets from a running dev server, and hardlinked the copy so editing it changed the shared `~/.wheels/docs` cache. It now copies the offline docs only when the mirror is missing or its `manifest.json` no longer matches the installed docs (so existing mirrors still refresh on upgrade), leaves a `public/wheels-docs` without a `manifest.json` alone, and warns instead of aborting your command if the copy fails
