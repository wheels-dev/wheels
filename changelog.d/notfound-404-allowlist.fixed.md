- Error pages now treat **404 as an allow-list** of the client-triggerable not-found types (`Wheels.RouteNotFound`, `Wheels.RecordNotFound`, `Wheels.ViewNotFound`, `Wheels.FileNotFound` from `sendFile()`, `Wheels.ActionNotAllowed`, `Wheels.ActionParameterMissing`) rather than mapping *any* `Wheels.*NotFound` to 404. Every other `*NotFound` — a missing package, model, method, filter, association, Vite asset/manifest, and any future type — is a server-side config/code fault and now returns HTTP **500** so monitoring sees it, instead of masquerading as a 404. (This generalises the `Table`/`DataSource`/`Column` → 500 fix.)
- An unsupported requested format (`Wheels.FormatNotAcceptable`, e.g. a `.ext`/`?format=` the action cannot answer) error page now returns HTTP **406 Not Acceptable** instead of 500.
