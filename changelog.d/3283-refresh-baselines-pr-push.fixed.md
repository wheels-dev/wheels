- The **Refresh visual baselines** workflow (`.github/workflows/refresh-visual-baselines.yml`) no longer pushes the refreshed PNG(s) directly to the dispatched branch, which the `develop` branch ruleset rejected with `GH013: Changes must be made through a pull request`. It now routes the refresh through a `chore/refresh-baseline-*` PR with auto-merge (via the new `tools/gh-open-refresh-baseline-pr.sh` helper) and grants the job `pull-requests: write` (#3283)
