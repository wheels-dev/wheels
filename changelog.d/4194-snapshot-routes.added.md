- Added `$snapshotRoutes()`, `$restoreRoutes()`, and `$clearRoutes()` to `wheels.WheelsTest` so tests that redefine the route table can snapshot and restore every route-derived structure (routes, staticRoutes, namedRoutePositions, the urlFor caches, and the router index) in one call, instead of hand-rolling a partial save/restore that leaks stale route state into later specs.
