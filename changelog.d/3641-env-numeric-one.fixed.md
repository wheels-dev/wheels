- A `.env` value of numeric 1 is no longer coerced to the boolean `true`. The generator template, the bundled examples and the `config dump` / `get settings` / `reload` CLI commands all tested booleans with `==`, which Lucee compares NUMERICALLY — `"1.0" == "true"` is true — so a numeric setting such as a sample rate of `1.0` arrived as a boolean and silently took its default instead (#3641)
