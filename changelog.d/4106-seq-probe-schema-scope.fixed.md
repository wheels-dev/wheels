- The Postgres/CockroachDB readiness probe for the `wheels_events` monotonic `seq` column now scopes its `information_schema.columns` lookup to the current schema (`AND table_schema = current_schema()`), so a same-named `wheels_events` table in another schema of the same database can no longer make the probe read the wrong table's column metadata and misreport readiness (follow-up to #4106)
