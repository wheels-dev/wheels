- The migrator dev-tool endpoints and the GUI pages that issue their anti-CSRF token now require the request's `Host` header to name the local machine (`localhost`, `127.0.0.1`, `[::1]`, or the `127.0.0.0/8` range), on top of the existing loopback-socket and no-forwarded-client checks. This ensures the development-only migrator tools answer only requests addressed to the local host. Add other local names you use with `set(migratorAllowedHosts="my.host,other.host")` (comma-delimited, empty by default).
