- The test runner's JSON report keeps its results when a spec errors with an exception that can't be serialized. Each spec's error, failure origin and bundle-level exception are reduced to plain values (type, message, detail, a bounded stack trace and template/line frames) before serializing; before, a JDBC exception on BoxLang sent the serializer into a `StackOverflowError` and the whole run came back with no results. If serialization still fails, the report keeps the totals and each spec's name and status. (#3905)
