- CLI boolean flags accept only `true` or `false`: `--force=yes`, `--force=1`, or any other value now fails with `Wheels.InvalidArguments` instead of being read loosely (a bare `--force` still means true, and `--no-force` false). Numeric options reject non-numbers, and a string option given as a bare flag (e.g. `--to` with no value) is an error (#2963)
- CLI commands and MCP tools reject unknown named arguments and named arguments with no value (an empty MCP string arrives as null) with `Wheels.InvalidArguments` naming the argument, instead of ignoring them. The global `--offline` flag is still accepted by every command (#2963)
