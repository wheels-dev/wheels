- **Breaking:** `findAll(returnAs="structs")` (and `"struct"`) now returns an array of structs, as documented, instead of a struct keyed by row number (`{1: {...}, 2: {...}}`). It serializes to a JSON array, and `ArrayLen()` works on it. Code that indexes rows (`rows[1]`) keeps working. Code that called `StructCount()`, `StructKeyList()` or `StructKeyArray()` on the result, or looped over its keys (`for (key in rows) { rows[key] }`), must switch to `ArrayLen()` and `for (row in rows)`. `findInBatches(returnAs="structs")` batches change the same way. See [Upgrading from 4.1 to 4.2](https://guides.wheels.dev/v4-1-0/upgrading/4x-1-to-4x-2/) (#4003)
- `findOne(returnAs="struct")` and `findByKey(returnAs="struct")` return the record's struct instead of a `{1: {...}}` wrapper, and `findEach(returnAs="struct")` now calls its callback for each record (it used to process nothing) (#4003)
