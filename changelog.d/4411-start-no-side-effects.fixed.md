- `wheels start` no longer changes `lucee.json` when it has nothing to start. Starting a server that is already running only reports it; it used to move the shutdown port on every repeat. `--dry-run` passes `--port` to LuCLI's dry run instead of writing it, and skips the registry clean-up, JDBC bundles, rewrite config and start token. `-p N` / `-p=N` work like `--port=N`, so the shutdown port is moved off the chosen port. `--dry-run` with `--engine=rustcfml` is refused, where it used to start the server (#4411)
- `wheels start --env=<name>` / `-e <name>` use the `lucee.json` environment profile, as `--environment=<name>` already did. LuCLI takes `--env` / `-e` as its own root option, so `wheels start` now forwards the value (#4412)
