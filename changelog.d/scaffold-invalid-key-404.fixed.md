- `wheels generate scaffold`: a key that can't belong to the model, such as `GET /posts/abc` for an integer primary key, now returns 404 instead of a 500 `Wheels.InvalidValue` error. The generated `requireRecord()` filter treats `Wheels.InvalidValue` from its `findByKey()` lookup as a missing record and rethrows any other error. The framework's check on typed key values is unchanged. **Controllers generated with an earlier version** should wrap the lookup in their `requireRecord()` the same way; the current version is in `app/snippets/CRUDContent.txt` of a new `wheels new` app (#3868)
