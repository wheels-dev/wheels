- Routing: with `URLRewriting="Off"`, `urlFor()` / `linkTo()` no longer double-encode custom route variables that end up in the query string. Route `blogs/[slug]` with `urlFor(route="blog", slug="a b")` now produces `slug=a+b` (the server receives `a b`) instead of `slug=a%2Bb` (the server received `a+b`); with HTML-attribute encoding (`linkTo`, `startFormTag`, …) the value is also HTML-encoded once instead of twice, which previously split the value on the `&` of the `&#x2b;` entity.
