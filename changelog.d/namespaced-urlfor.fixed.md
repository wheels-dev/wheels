- `urlFor()` / `linkTo()` now build namespaced controller paths segment by segment, so unnamed generic routes keep their namespace (`/admin/users/show/1`) instead of producing `admin%2-fusers` / `admin.-users` (dotted `params.controller`, explicit `controller="admin/users"`, action-only calls). Named routes, non-namespaced hyphenation, keys/formats and query-string encoding are unchanged (#4695)
