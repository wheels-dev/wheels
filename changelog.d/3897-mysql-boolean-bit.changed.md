- On MySQL, `t.boolean()` / `addColumn(columnType="boolean")` now create a `BIT(1)` column instead of `TINYINT(1)`. A DSN with `tinyInt1isBit=false` reported `TINYINT(1)` as a plain integer, so the model validated boolean properties as numbers ("is not a number"). Existing `TINYINT(1)` columns are unchanged: drop `tinyInt1isBit=false` from the DSN, or convert the column with `changeColumn(columnType="boolean")`. `BIT(1)` values read back as `1` on Lucee and Adobe and as `true` on BoxLang; both are truthy and compare equal in CFML (#3897)
