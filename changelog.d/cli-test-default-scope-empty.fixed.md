- `wheels test` on an app with no specs yet, such as a fresh `wheels new` app, now prints a "No specs yet" notice with a hint (`wheels generate test model <Name>`) and exits 0. Before, it failed with "no test bundles ran for this scope". This applies only to the default scope: an explicit `--filter`, `--directory` or path that runs no bundles still fails, and so does any run with failures, errors, a rejected scope or specs that failed to load (#3921).
