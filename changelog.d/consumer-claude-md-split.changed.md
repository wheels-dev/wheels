- The `CLAUDE.md` that ships with apps (from `wheels new`, the starter app and the core package) is now short enough for AI coding tools that cap or skip the middle of long files: conventions, common mistakes, testing and a topic index, under 8 KB (it was over 32 KB). The reference topics (models, routing, views, caching, middleware, DI, auth, storage, packages, migrations, jobs, SSE) moved unchanged to `.ai/<topic>.md`, and `AGENTS.md` tells agents to open a topic file when the task reaches it. Existing apps can copy `CLAUDE.md`, `AGENTS.md` and `.ai/` from a new `wheels new` app. The build check now enforces the size budget and that every topic file is linked from the index. (#3960)
