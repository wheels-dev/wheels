- Table names containing `$` (e.g. `admin$users`) work again: 4.1.0's `$dbinfo()` identifier check rejected them and stopped the app from initializing. `$` is now accepted after the first character there and in the AutoMigrator, ORDER BY / GROUP BY dot-notation, and QueryBuilder identifier checks, so a paginated `findAll()` on a `$` table works too; those identifier checks still reject quotes, `#`, and a leading `$` (#3669)
