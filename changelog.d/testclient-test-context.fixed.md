- A `wheels.wheelstest.TestClient` created inside a test run now sends its requests to the test application, as `$testClient()` already did. Before, a client built with `new wheels.wheelstest.TestClient()` or an app subclass reached the live application and its primary datasource while the spec code used `<datasource>_test`. Pass `testContext=false` to address the live application. A client created outside a test run, such as in a thread or a script, is unchanged.
