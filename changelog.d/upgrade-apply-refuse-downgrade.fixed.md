- `wheels upgrade apply` no longer silently downgrades the framework when the app's `vendor/wheels/` is newer than the CLI's bundled copy (for example, an app created with a newer CLI or a `wheels-be` snapshot). It now refuses before changing anything, names both versions, and suggests installing a newer CLI; pass the new `--allow-downgrade` flag to install the older framework anyway. The summary now says `upgraded`, `downgraded` or `reinstalled` to match what actually happened
