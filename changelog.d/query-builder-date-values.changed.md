- A date passed to the query builder (`where()`, `whereBetween()`, `whereIn()`) or a dynamic finder (`findOneByPublishedAt(date)`) now compares as a date on SQLite. It used to reach the SQL as its CFML literal (`{ts '...'}`), which never matched a stored date, so the query silently returned no rows. Other databases already parsed that literal; they now receive the plain date text too.
