- A request for a format the action does not provide now answers `406 Not Acceptable` instead of `200` with an empty body. On a controller that only `provides()` html, `GET /posts/2.json`, `/posts/2.xml` or `/posts/new.json` used to return an empty `200`. When the `format` param (the route's `.[format]` segment or `?format=`) names a format outside the action's `provides()` / `onlyProvides()` list, or a provided `json` / `xml` format the action never renders (no template and no `renderWith()` call), and the action rendered nothing itself, the automatic render now throws `Wheels.FormatNotAcceptable` with status 406 in development and returns a plain-text `406 Not Acceptable` response when `showErrorInformation` is off. Html requests, formats the action renders, `renderWith()` (which still falls back to the html view) and formats negotiated from the `Accept` header are unchanged (#3866)
