- The test-runner application isolation (`<name>_wheelsTest`, #3374) is now selected only in the `development` and `testing` environments. The runner path is matched against the request path. The `X-Wheels-Test-Context` header and `WHEELS_TEST_CONTEXT` cookie must carry the per-process runner secret and come from a loopback client. An isolated application refuses to start outside development and testing before any of its start-up code runs, and the core and app test runners refuse to run in production. **Existing apps:** test-context isolation needs `WHEELS_ENV` set to `development` or `testing` (the `wheels new` template sets it). Without it, specs run against the live application scope, and the runner logs an isolation-off warning and sends an `X-Wheels-Test-Isolation: off` response header.
