- MCP tool calls now honour positional parameters. LuCLI's MCP server passes every `tools/call` argument by name, and `ArgSpec.parse()` bound positionals only from typed tokens, so advertised properties such as `destroy`'s `type`/`name` and `analyze`'s `target` were silently ignored. `db`, `packages`, and `reload` also advertise real input schemas now, built from the same `ArgSpec` their parsers use (#2963)
