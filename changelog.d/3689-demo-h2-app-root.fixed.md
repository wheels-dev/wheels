- The repository's demo app now keeps its H2 database under its own root (`db/h2/wheels-dev.h2.db`). Its datasource used the relative path `jdbc:h2:file:./db/h2/wheels-dev`, which resolves against the server process's working directory: for a LuCLI server that is the Lucee Express install, so every demo-app server on the machine, from any checkout or worktree, shared (and locked) one file at `~/.wheels/express/<lucee-version>/db/h2/wheels-dev.h2.db` (or `~/.lucli/express/<lucee-version>/db/h2/` for servers started with a plain `lucli` binary). To keep existing demo data, stop the demo servers and copy that file into `db/h2/` of the checkout that should own it; otherwise the demo database starts empty. Apps created with `wheels new` already anchor their SQLite/H2 paths to the app root and are unaffected (#3689)
