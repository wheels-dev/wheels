- The H2 migrator now quotes generated DDL identifiers in the datasource's own fold case, so migrations can create reserved-word tables and columns (e.g. `"order"` / `"group"` in the H2 upper fold) and still alter, rename or drop existing unquoted schemas. With identifier folding off it keeps the legacy unquoted path, and `migratorObjectCase` only applies in that case. Phase 1 of the cross-adapter DDL quoting work (#4629)
