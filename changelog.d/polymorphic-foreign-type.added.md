- `belongsTo(polymorphic=true)`, `hasMany(as=...)` and `hasOne(as=...)` accept a `foreignType` argument naming the polymorphic type column, so an underscore-shaped schema (`commentable_id` / `commentable_type`, as `t.references(polymorphic=true)` writes it with `useUnderscoreReferenceColumns`) works when both `foreignKey` and `foreignType` are passed. The default stays `<name>type`
