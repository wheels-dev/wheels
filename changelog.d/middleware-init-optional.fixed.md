- A middleware registered by component path (`set(middleware=["app.middleware.TokenGate"])` or a route's `middleware=[...]`) no longer needs an `init()`: Wheels calls `init()` only when the component has one. A component with just `handle(request, next)`, which is all `wheels.middleware.MiddlewareInterface` requires, used to fail every request with "has no function with name [init]". An `init()` the component has, including an inherited one, still runs, and an object it returns is still what's used; when it returns nothing or a non-object, the component itself is used.
