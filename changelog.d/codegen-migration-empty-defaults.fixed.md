- The migration templates (`wheels generate migration`, the development migrator, new apps' `app/snippets/dbmigrate/`) no longer show `default=''` / `default=""`, which the migrator has rejected on string, text and char columns since 4.1.0. The example header in `create-table` and `change-table`, and the `changeColumn` / `addColumn` calls in `change-column` and `remove-column`, now omit the default.
