- `linkTo()` and `URLFor()` do less work per call on JVM engines (Lucee, Adobe, BoxLang): `URLFor` skips a redundant argument-normalisation pass when `linkTo` already resolved the arguments, route-variable substitution uses literal string operations instead of a regular expression per variable, and `$tag` resolves the HTML-attribute-encoding setting once per tag rather than once per attribute. The generated output is byte-for-byte unchanged. ([#4151](https://github.com/wheels-dev/wheels/issues/4151))
