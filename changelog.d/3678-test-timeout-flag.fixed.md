- `wheels test --test-timeout=<seconds>` sets the test run's time budget from the terminal. The documented `wheels test --timeout=<seconds>` never reached the command there: LuCLI's own global `--timeout` option takes it (a non-integer is rejected by LuCLI, and a valid value was silently swallowed), so only `WHEELS_TEST_TIMEOUT` worked. MCP clients keep passing `timeout`; precedence is the explicit value, then `WHEELS_TEST_TIMEOUT`, then 900, and a value that is not a positive number warns and falls back as before (#3678)
