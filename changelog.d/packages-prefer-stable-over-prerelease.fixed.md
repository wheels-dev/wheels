- `wheels packages add` and `update` now install the stable release instead of an equal pre-release (e.g. `1.2.0` over `1.2.0-rc.1`), an exact pin such as `@1.2.0` no longer matches `1.2.0-rc.1`, and pre-release versions are only considered when the pin names one (`@1.2.0-rc.1`); the CLI's SemVer comparison now orders pre-release labels per SemVer 2.0.0, and `update` no longer downgrades an installed pre-release that is newer than the latest release
