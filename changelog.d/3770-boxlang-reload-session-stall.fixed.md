- On BoxLang, a reload (`?reload=true&password=…` or the CLI's `X-Wheels-Reload-Password` header) no longer stalls for the reload lock's timeout (180 s per wave, 360 s and more seen) while the application has active sessions, and each session's `onSessionEnd` handler now runs during the reload instead of being skipped with a lock-timeout error. BoxLang ends sessions on worker threads inside `applicationStop()`, while the reload request holds the exclusive reload lock; `$simpleLock()` now records the restart in the application scope, and a session end that finds that marker runs without waiting for the lock the parked restart holds. The fix is in the framework: existing apps need no change to `public/Application.cfc` (#3770)
